= {lab_name} : A Capture The Flag game.

This lab is a Capture The Flag (CTF) game.

A flag is an element of information related to security, such as a password, an IP address... that has to be discovered in a "mission".

This CTF has 4 missions (in addition to mission zero), so there are 5 flags for you to discover.

The mission briefing, your environment architecture, and useful tools and documentation are listed and described on the next pages.

Successive missions are described directly by the CTF Dashboard when they are unlocked.

== What you'll learn?

In this challenge, you will:

* Investigate security vulnerabilities in an OpenShift environment.
* Analyze compromised applications and CI/CD pipelines.
* Use Red Hat Advanced Cluster Security to identify threats.
* Understand OpenShift GitOps and Pipelines security.
* Apply DevSecOps principles to find and exploit security weaknesses.
* Learn secure coding and infrastructure practices.

== Who is this for?

This challenge is designed for developers, administrators, security professionals, and platform engineers who want to:

* Practice DevSecOps skills in a safe environment.
* Learn about common security vulnerabilities in cloud-native applications.
* Understand how attackers exploit weaknesses in CI/CD pipelines.
* Gain hands-on experience with Red Hat security tools.

== Expected outcomes

After completing this challenge, you will:

* Discover multiple security flags by exploiting vulnerabilities.
* Gain practical experience with security tools and Red Hat technologies (Red Hat Advanced Cluster Security (ACS), OpenShift GitOps, and OpenShift Pipelines).
* Understand common attack vectors in cloud-native environments.
* Learn how to identify and prevent similar breaches.
* Develop stronger DevSecOps investigation skills.

== Prerequisites

This challenge assumes:

* Basic understanding of Kubernetes and OpenShift.
* Familiarity with CI/CD concepts.
* Basic command-line skills.
* Understanding of security concepts (secrets, authentication, and authorization).
* Problem-solving mindset.
